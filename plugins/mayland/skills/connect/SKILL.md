# Connect

Use Claude's built-in MCP connection controls for the Mayland server.

- If Mayland is already connected, do not repeat setup.
- If authentication is required, choose **Authenticate** once and complete the browser approval.
- Mayland has already prepared the private connection handoff in the browser.
- Never request, display, paste, or explain pairing codes, setup tokens, OAuth credentials, or other secret material.
- Do not run terminal setup commands or consume model tokens polling for browser authorization.
- After authentication, verify that the Mayland MCP server is connected.
- Run `/reset` before starting a new email or resuming after a reconnect.
